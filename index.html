Sobre

Engenharia sólida primeiro. IA em cima disso.

Sou engenheiro de software em Florianópolis. Passei mais de uma década construindo APIs REST, integrações e arquiteturas backend com Node.js, TypeScript e bancos SQL e NoSQL.

Também atuei como Tech Lead, liderando times de até 15 pessoas em projetos globais, e conduzi decisões técnicas difíceis: evoluir sistemas de monolito para microsserviços no ritmo do negócio, instrumentar latência com OpenTelemetry, Grafana e Datadog, migrar de SQL para NoSQL e cortar custo de infraestrutura com cache em vez de servidor maior.

Agora estou focado em AI Engineering: RAG, embeddings, agentes com LangGraph, tool calling e observabilidade de LLMs. Meu objetivo é levar IA generativa para produção com o mesmo rigor de qualquer outro sistema: testes, custo medido, latência sob controle.

Cases

Decisões técnicas que pagaram a conta

Arquitetura · Evolução

Do monolito aos microsserviços, no tempo certo

Começar com um monolito para entregar rápido, reorganizar em monolito modular quando os domínios ficaram claros e extrair microsserviços só quando a escala e os times pediram.

− microsserviços cedo demais
+ monolito → monolito modular
+ microsserviços conforme o crescimento
Observabilidade · Latência

Medir antes de otimizar

Instrumentação com OpenTelemetry, dashboards no Grafana e monitoramento no Datadog para achar os gargalos de latência com dados, não com palpite.

− "o sistema está lento"
+ traces distribuídos (OpenTelemetry)
+ p95/p99 e alertas no Grafana e Datadog
Performance · Custo

Cache antes de escalar servidor

Endpoints travando e pesando no servidor. Em vez de aumentar a máquina, coloquei uma camada de cache com Redis nos pontos quentes.

− upgrade de servidor
+ Redis nos endpoints críticos
+ custo final menor para o cliente
Dados · Escala

Migração de SQL para NoSQL

Bancos com alto volume chegando ao limite. Conduzi a escala e a migração do modelo relacional para NoSQL onde o padrão de acesso pedia.

− gargalo no banco relacional
+ modelo orientado ao acesso
+ escala horizontal
IA · Automação

Agentes no lugar do processo manual

Consultas de RH e operações de estoque eram feitas à mão. Desenhei agentes na AWS Bedrock que executam essas tarefas direto nos sistemas.

− execução manual
+ agentes com tool calling
+ estoque consultado em tempo real
